README: Analysis of SRF Earmarks

This README explains the data, repository structure and scripts, and how to run the analysis for the October 2025 report, "Revolving No More: How Earmarks Undermine Funding for Water Infrastructure.” The project analyzes the short- and long-term impacts of earmarks on the Clean Water State Revolving Fund (CWSRF) and the Drinking Water State Revolving Fund (DWSRF) programs.

Project Overview
The State Revolving Fund (SRF) programs are partnerships between federal and state governments that provide mainly loans for water infrastructure projects. Loan repayments are reinvested, creating a sustainable "revolving" source of funding. This analysis examines the impact of congressional earmarks, which are issued as grants and do not revolve back into the funds. The aim of this project is to quantify how earmarks affect funding distribution across states, the types of communities that receive assistance, and the long-term financial impact.

Data Sources
The analysis relies on four primary data sources as detailed in the report's appendix:
	•	EPA Allotment Memoranda: Official documents detailing the distribution of CWSRF and DWSRF capitalization grants to states for FY23 and FY24. This data is contained within raw_data/earmarks_data.xlsx.
	•	Congressional Earmark Lists: Publicly available lists of Community Project Funding (House) and Congressionally Directed Spending (Senate) items for FY23 and FY24. This data is also contained within raw_data/earmarks_data.xlsx.
	•	EPA SRF Public Portal: Project-level information from SRF assistance agreement reports, used for both demographic analysis and historical data for the long-term models. These are the national assistance agreement detail reports in raw_data/.
	•	U.S. Census Bureau: Demographic data from the 2022 American Community Survey (ACS) 5-year estimates, including population, median household income, poverty rates, and racial composition at the "place" level.

Running the Analysis
The scripts should be run in the following order to ensure dependencies are met.

Step 1: Prepare Project-Level Demographic Data
00_prj_level_dem_data.r fetches ACS data, loads all project lists (both earmarks and state-allocated), matches them to a Census-defined "place," and saves the final merged dataset. This script generates raw_data/prj_level_dem_data.csv 

Step 2: Analyze Short-Term Impacts
01_analysis_short_term_impacts.r loads the data generated in Step 1 and the state-level funding data to produce the visualizations for the report's short-term impact section (Figures 1-7).
 
Step 3: Run Long-Term Cash Flow Models
4_DW.R and 4_CW.R run the 20-year cash flow models for the DWSRF and CWSRF programs, respectively. They can be run independently of each other and of the short-term analysis script.

The methodology is explained in the appendix of the report.
